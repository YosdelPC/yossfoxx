Cómo subirlo a GitHub desde el teléfono

  1. Descarga juegos.json y cada portada con los botones de esta página.
  2. Abre la app de GitHub → repositorio YosdelPC/yossfoxx.
  3. Entra a la carpeta doc → sube juegos.json y elige reemplazar el actual → commit a main.
  4. Entra a assets → imagenes → portadas → sube cada portada nueva (00184.webp, etc.) → commit a main.
  5. Espera de 2 a 5 minutos y abre la tienda para comprobar que el juego ya sale.
  6. El PDF del catálogo no lo genera esta página: se actualiza cuando hables con Muse.
  7. Si el juego estaba pedido en Pedidos de Usuarios, díselo a Muse para marcarlo como Agregado.
